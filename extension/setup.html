Install the helper app

Opening links in another browser needs a small helper program that the extension cannot install by itself. Paste this into a terminal:

It downloads install.sh and native_host.py for this version from the project's repository, installs the helper into ~/.local/bin, and registers it with every Chromium-based browser it finds, allowing only this extension's ID. It needs curl and python3. Browsers installed as Flatpak or Snap usually cannot start helper programs.
